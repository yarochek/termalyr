# termalyr

Song lyrics in the terminal

## How it works?

The script detects the track using playerctl that is currently playing, searches for matching lyrics on lrclib.net, and downloads the lyrics file to the computer for offline use.

## Install

### AUR
```bash
yay -S termalyr
```
